<br/>

> **Zonnecto** is a production-ready, full-stack **anonymous real-time chat platform** connecting strangers in a safe, moderated environment.

| Feature | Stack |
|---|---|
| 🎲 Random Matchmaking | Redis Queue + Smart Filters |
| 💬 Real-Time Messaging | WebSocket + STOMP Protocol |
| 👥 Friend System | Persistent FRIEND_CHAT Rooms |
| 🛡️ Moderation | Auto-ban, Reports, Admin Panel |
| ⭐ Premium System | Razorpay Integration |
| 🔐 Auth | JWT + BCrypt + OTP Verification |

```
Frontend: React 18 + Vite + TailwindCSS → Netlify
Backend:  Spring Boot 3.2 + Java 17     → Render
Database: PostgreSQL (Neon)             → Cloud
Cache:    Redis (Upstash)               → Cloud
```
